# Kings' Valley Secrets - VR Game

**Greentech For Mobile Software** (Investment Law 72/2017, 6th of October, Egypt).

## Overview
An immersive Virtual Reality (VR) experience designed for international tourists and history enthusiasts. Players use real-player 3D scanning to step into ancient Egypt, exploring historical milestones from the unification of Upper and Lower Egypt to the discovery of the Valley of the Kings, enhanced by AI-driven cinematics and characters.

## Key Features
- **Real-Player 3D Avatar Integration**
- **AI-Generated Cinematic Teasers for Each Historical Era**
- **Accurate Historical Reconstruction of Ancient Egyptian Architecture & Technology**

## Development Stack
- **Engine:** Unreal Engine 5 / Unity
- **Version Control:** Git & Git LFS
